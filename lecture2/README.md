Open `exercise.ipynb` in a Python notebook environment from this directory or the
project root. Keep `data/` and `_helm_reveal.py` beside it. Once dependencies are
installed, the exercise needs no network access.

Dependencies: PyTorch, NumPy, pandas, Matplotlib, scikit-learn, and IPython.
The notebook supplies a fixed PyTorch starter for Task 2; students write their
models, data preparation, training loops, and experiments.

The supplied notebook has no worked answers. Every code cell is marked TODO or
RUN ONLY. Unfinished tasks can be skipped; final evaluations stay locked until
the corresponding readiness flag is set. `_helm_reveal.py` contains spoilers and
is loaded only after the final Allocation Helm submission.

Validation uses CPU PyTorch. Checks cover notebook execution, the starter and
two affordable repairs, final scoring, and the original Helm reference scores.
